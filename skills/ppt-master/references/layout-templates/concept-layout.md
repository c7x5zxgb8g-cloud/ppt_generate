# Concept Layout

Use for `courseware_type: concept`.

## Layer Plan

- `layer-background`: low-distraction background.
- `layer-context`: prior knowledge or guiding question.
- `layer-content`: concept name, definition, intuition, key points.
- `layer-interaction`: quick check question or "think for 20 seconds" prompt.
- `layer-guidance`: teacher hint / visual arrow / misconception warning.
- `layer-chrome`: title and navigation.

## Layout

- Concept badge on one side.
- Definition block as the visual anchor.
- 2-3 key point chips below or beside it.
- Optional example mini-card.

## Content Rules

- One concept per slide.
- Max 3 new terms.
- Definition is student-facing: short, accurate, not encyclopedia prose.
