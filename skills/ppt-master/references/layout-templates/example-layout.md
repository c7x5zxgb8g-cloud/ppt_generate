# Example Layout

Use for `courseware_type: example`.

## Layer Plan

- `layer-background`: neutral classroom base.
- `layer-context`: problem statement.
- `layer-content`: solving steps.
- `layer-guidance`: key-step highlight and teacher hint.
- `layer-feedback`: final answer and common mistake.
- `layer-chrome`: title, difficulty tag, page number.

## Layout

- Top problem box.
- Middle step-by-step solution, max 5 steps.
- Right rail or bottom strip for key insight.
- Feedback area should be easy to reveal last.

## Content Rules

- Do not reveal all reasoning as a paragraph.
- Highlight why a step is valid.
- Speaker notes include common mistake and follow-up question.
