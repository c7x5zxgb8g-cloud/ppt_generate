# Summary Layout

Use for `courseware_type: summary`.

## Layer Plan

- `layer-background`: calm closing background.
- `layer-content`: knowledge map, checklist, or retrieval grid.
- `layer-interaction`: reflection prompt or exit ticket.
- `layer-feedback`: optional model answer / final takeaway.
- `layer-chrome`: title and lesson label.

## Layout

- Center knowledge map or 2x2 / 3x2 grid.
- Use icons only as retrieval anchors, not decoration.
- Add a final transfer question.

## Content Rules

- Cover all core knowledge points.
- Prefer retrieval cues over a long recap paragraph.
- End with "where to use this next" or a reflective question.
