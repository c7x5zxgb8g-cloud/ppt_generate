# Quiz Layout

Use for `courseware_type: quiz`.

## Layer Plan

- `layer-background`: simple, spacious background.
- `layer-context`: question stem.
- `layer-interaction`: answer options, blank workspace, or voting area.
- `layer-guidance`: optional hint.
- `layer-feedback`: correct answer, explanation, misconception note.
- `layer-chrome`: title, timer, page number.

## Layout

- Large question area.
- 2-4 option cards or a clear fill-in response area.
- Feedback panel placed off to the side or bottom for staged reveal.

## Content Rules

- One question per slide unless explicitly a rapid drill.
- Answer must exist in `layer-feedback`.
- Speaker notes include reference answer and expected student reasoning.
