# Objectives Layout

Use for `courseware_type: objectives`.

## Layer Plan

- `layer-background`: calm subject-themed background.
- `layer-context`: lesson hook or essential question.
- `layer-content`: 3-5 measurable objectives.
- `layer-guidance`: success criteria or "完成后你将能..." cue.
- `layer-chrome`: title, lesson label, page number.

## Layout

- Header: lesson title + subject/grade tag.
- Left or top area: motivating question / scenario.
- Main area: objective cards or checklist.
- Bottom area: success criteria.

## Content Rules

- Use observable verbs.
- Each objective should fit one line plus short clarification.
- No more than 5 objectives.
