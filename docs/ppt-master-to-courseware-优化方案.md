## 1. 项目愿景与目标

### 愿景

从"通用演示文稿生成器"进化为**基于 AI 的教学课件自动生成系统**，让教师只需提供教材/大纲源材料，即可获得符合教学设计规范的原生可编辑 PPTX 课件。

### 目标用户

- 中小学教师（K-12）
- 教育培训机构课程开发人员
- 高校助教/讲师

### 核心价值主张

| 维度 | 原项目 | 魔改后 |
|------|--------|--------|
| 页面类型 | 通用幻灯片 | 教学目标/概念讲解/例题/练习/总结 |
| 内容结构 | 线性页面流 | 知识点图谱 + 课时规划 + 难度分层 |
| 教学设计 | 无 | Bloom 认知层次 + 5-7分钟节奏原则 |
| 互动性 | 无 | 随堂练习 + 课堂互动建议 |
| 输出质量 | 外观美观 | 美观 + 教学有效性 |

## 5. 新增文件详细设计

### 5.1 `courseware-types.md` — 课件页面类型体系

```markdown
# 课件页面类型体系

## 类型总览

| 类型ID | 名称 | 用途 | 每课时建议数量 | 复杂度 |
|--------|------|------|---------------|--------|
| objectives | 教学目标页 | 展示本节课学习目标 | 1 | 低 |
| concept | 概念讲解页 | 讲解核心知识点 | 4-6 | 中 |
| example | 例题演示页 | 展示典型例题及解题过程 | 1-2 | 中-高 |
| quiz | 随堂练习页 | 学生互动练习 | 1-2 | 中 |
| comparison | 对比分析页 | 对比相近概念 | 0-1 | 中 |
| diagram | 图表数据页 | 数据可视化展示 | 0-1 | 中 |
| summary | 知识总结页 | 课时知识点回顾 | 1 | 低 |

## 页面类型要求矩阵

### objectives（教学目标页）
- 布局节奏：anchor
- 元素：标题 + 目标列表（3-5条）+ 装饰图标
- 字体：标题 36-40pt，正文 22-26pt
- 建议配色：品牌色/蓝色系

### concept（概念讲解页）
- 布局节奏：breathing
- 元素：核心概念标题 + 定义文本框 + 关键要点列表 + 可选示例
- 字体：概念标题 30-34pt，定义 22-24pt，要点 18-20pt
- 建议配色：不同知识点使用不同强调色

### example（例题演示页）
- 布局节奏：dense
- 元素：题目区（顶部）+ 解题步骤列表 + 关键步骤高亮
- 字体：题目 22-24pt，步骤 18-20pt
- 特殊要求：解题步骤最多 5 步，使用编号列表

### quiz（随堂练习页）
- 布局节奏：breathing（留白给思考时间）
- 元素：题目 + 选项（2-4个）/ 判断对错 / 填空题
- 字体：题目 22-24pt，选项 18-20pt
- 特别：备注中添加参考答案和解析

### summary（知识总结页）
- 布局节奏：anchor
- 元素：标题 + 知识点网格（2×2 或 3×2）+ 核心公式/定理
- 字体：知识点标题 22pt，说明 16-18pt
```

## 6. 课件页面类型体系

### 6.1 类型定义速查

```
每节课的标准页面构成（10页左右）：

┌─ 第1页  教学目标页  (objectives)
├─ 第2页  概念讲解 ①  (concept)
├─ 第3页  概念讲解 ②  (concept)
├─ 第4页  例题演示 ①  (example)
├─ 第5页  概念讲解 ③  (concept)
├─ 第6页  随堂练习 ①  (quiz)
├─ 第7页  概念讲解 ④  (concept)
├─ 第8页  例题演示 ②  (example)
├─ 第9页  概念讲解 ⑤  (concept)
└─ 第10页 知识总结页  (summary)
```

**原则：**
- 概念讲解后紧跟例题（理论→实践）
- 每 3-4 个概念后插入练习（检验理解）
- 难度递增（easy → medium → hard → summary）
- 每 5-7 分钟一个节奏切换点（保持注意力）

### 6.2 与现有系统的集成

现有的布局节奏标签 `anchor/dense/breathing` 保留，与页面类型形成**组合关系**：

```
页面类型 → 默认布局节奏 → 可选的备选节奏
─────────────────────────────────────────────
objectives → anchor      → breathing
concept    → breathing   → anchor（重点概念）
example    → dense       → breathing（复杂例题）
quiz       → breathing   → dense（多题）
comparison → dense       → anchor
summary    → anchor      → breathing
```

## 7. AI 提示词优化策略

### 7.1 角色设定对比

| 维度 | 原项目 | 课件版 |
|------|--------|--------|
| 身份 | 演示文稿设计师 | 资深教学设计师 + 学科专家 |
| 专业领域 | 视觉设计、排版 | 教学设计、学科教学法、认知心理学 |
| 核心原则 | 美观、清晰、品牌一致性 | 教学有效性、知识准确性、认知负荷管理 |
| 输出目标 | 听众被说服/被吸引 | 学生理解并掌握知识点 |

### 7.2 需新增的提示词约束

```
## 教学规范（新增强制规则）

1. **知识点准确性**
   - 每个概念引用必须准确，不确定时标注"建议人工核实"
   - 例题必须有标准答案或解题思路
   - 禁止编造统计数据和历史事实

2. **认知负荷管理**
   - 每页信息量控制在 Miller 7±2 法则内
   - 复杂概念使用"渐进揭示"（逐步展示，而非全部抛出）
   - 同一页不出现超过 3 个新术语

3. **难度递进**
   - 同一课时内：基础知识 → 进阶概念 → 应用实践
   - 同一页面内：定义 → 示例 → 练习（I do → We do → You do）

4. **互动设计**
   - 每个 quiz 页的演讲者备注中包含：
     - 参考答案
     - 常见学生错误及应对策略
     - 建议提问方式（面向全班/小组讨论/个人思考）
```

## 9. 公式渲染方案

### 9.1 方案选型对比

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **LaTeX → SVG → PPTX** | 质量最高，原生支持数学符号 | 需要 LaTeX 环境或 MathJax 服务 | ⭐⭐⭐⭐⭐ |
| **LaTeX → SVG → PNG 嵌入** | 实现简单 | 不可编辑，缩放可能模糊 | ⭐⭐⭐ |
| **MathML 直接嵌入 DrawingML** | 原生可编辑 | PowerPoint 支持有限 | ⭐⭐ |

### 9.2 推荐技术路线

```
LaTeX 公式
    │
    ▼
MathJax / KaTeX (Node.js 或 Python 绑定)
    │
    ▼
SVG (viewBox 尺寸与课件主题匹配)
    │
    ▼
嵌入到课件 SVG 布局中
    │  ┌─ 行内公式：作为 <text> 元素的替代
    │  └─ 独立公式：作为独立的 <image> 或 <g> 元素
    ▼
finalize_svg.py → svg_to_pptx.py
    │
    ▼
PowerPoint 中原生渲染的公式
```

### 9.3 实现注意事项

- 公式字号需与正文字号协调（通常是正文的 100-110%）
- 复杂公式（积分、矩阵）需分配更大的布局空间
- 化学方程式可复用同一管道，添加化学专用包支持

## 10. 内容校验机制

### 10.1 三层校验体系

```
          ┌─ 第一层：AI 生成阶段  ──────────────────────────┐
          │  提示词中约束："不确定的内容标明"建议人工核实"     │
          │  知识点提取时标注置信度                            │
          └────────────────────────────────────────────────┘
                                    │
          ┌─ 第二层：自动化检查  ────────────────────────────┐
          │  check_knowledge_consistency.py                  │
          │  - 知识点前后页是否一致                          │

          │  - 例题答案与解题步骤是否匹配                    │

          │  - 单位符号是否规范（kg 不写作 KG）              │
          └────────────────────────────────────────────────┘
                                    │
          ┌─ 第三层：人工审核门控  ──────────────────────────┐
          │  ⛔ BLOCKING 步骤                                │
```

## 11. 质量检查扩展

### 11.1 新增检查项

在现有的 `svg_quality_checker.py` 基础上，课件模式增加以下检查：

```python
COURSEWARE_CHECKS = {
    'knowledge_consistency': {
        'level': 'error',
        'check': '同一知识点在不同页面中的表述是否一致'
    },
    'terminology_standard': {
        'level': 'warning',
        'check': '学科术语是否符合国家标准'
    },
    'difficulty_distribution': {
        'level': 'warning',
        'check': '难度分布是否合理（easy:medium:hard ≈ 3:5:2）'
    },
    'page_type_balance': {
        'level': 'warning',
        'check': '页面类型分配是否满足课件规范'
    },
    'learning_objectives_coverage': {
        'level': 'error',
        'check': '教学目标是覆盖了所有核心知识点'
    }
}
```

### 11.2 执行流程

```
生成所有 SVG 后 → 运行 svg_quality_checker.py（标准检查）
                → 运行 check_knowledge_consistency.py（课件专项）
                → 运行 check_terminology.py（术语专项）
                → 输出课件质量报告
                → ⛔ 人工审核
                → 修复 all errors
                → 确认 warnings
                → 进入后处理流水线
```
