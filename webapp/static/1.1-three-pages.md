# 1.1 三页测试源

以下内容从 1.1.md 中抽取第 1-3 页，用于 Web 端到端短链路测试。请只生成 3 页 PPT。

## 全局视觉设定

- 风格：可爱的侦探探案风 + 儿童教育插画风。
- 背景：温暖复古牛皮纸色、旧书页米黄色、软木板、红线索线、放大镜、铅笔，温馨神秘但不恐怖，适合小学生。
- 数字人：豆包侦探，戴侦探帽，拿放大镜，可爱卡通豆沙包形象。
- 输出：严格生成 3 页，页码和内容对应第1页、第2页、第3页。
